# Primitive Sweep

The primitive sweep searches historical computational mechanisms for high-leverage machine-native structure.

Each primitive is tested as a mechanism, not cited as historical trivia.

For every primitive record:

- mechanism
- minimal implementation
- contract
- baseline
- activation
- kill test
- measured effect
- composition candidates
- evidence location
