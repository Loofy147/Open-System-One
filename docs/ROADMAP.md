# Roadmap

## M0 — Contract

- typed decision objects
- finite outcome spaces
- deterministic validation
- keyed results
- batch backend interface

## M1 — Real execution

- browser ONNX reference
- reproducible dataset loading
- candidate-set intervention
- raw evaluation receipts

## M2 — Learned decision head

- trainable head over frozen representations
- batch independence tests
- calibration evaluation
- comparison with pairwise baseline

## M3 — Runtime portability

- ONNX
- MLX
- CoreML/ANE
- Android

## M4 — Control-plane integration

- claims/evidence/experiments/runs/artifacts
- capability and authority separation
- deterministic policy execution

Every milestone remains provisional until its acceptance tests and evidence are recorded.
