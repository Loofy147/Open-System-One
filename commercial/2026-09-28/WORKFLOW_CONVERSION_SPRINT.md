# Workflow Conversion Sprint

## What is sold

One concrete operational result, not generic AI consulting.

Examples:
- inbound lead -> qualification -> CRM update;
- support email -> classification -> knowledge retrieval -> draft response;
- form/document -> extraction -> structured record;
- API -> normalized data -> internal system;
- existing AI workflow -> reliability repair + verification.

## Deliverable contract

Input:
one workflow, its current behavior, constraints and acceptance condition.

Output:
- implemented workflow or integration;
- explicit validation/error paths;
- test evidence;
- short handoff document;
- reproducible artifact where feasible.

## Pricing ladder for first transactions

R0: paid diagnosis / repair — $75-$200
R1: one bounded workflow — $250-$750
R2: integrated workflow package — $750-$2,000
R3: maintenance / monitoring — recurring

These are experiment prices, not market guarantees.

## Sales constraint

Sell the outcome in the buyer's language:
less manual transfer, fewer missed leads, fewer support steps, faster processing, a working integration, or a repaired workflow.

Do not lead with "AI agent" unless the buyer's problem actually depends on it.

## Evidence advantage

Every delivery produces:
Before -> Change -> Test -> Observed outcome -> Receipt.

That receipt becomes the next sales asset.
